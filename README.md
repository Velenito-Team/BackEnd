# Backend - El Veleñito

Backend del sistema web para la gestión de tiendas de barrio y pequeños
supermercados **El Veleñito**. Este proyecto hace parte de la asignatura de
Ingeniería de Requerimientos y se encuentra actualmente en desarrollo.

## Descripción

El sistema busca centralizar los procesos básicos de un negocio que
tradicionalmente se gestionan de forma manual, como el inventario, las ventas,
la caja, los pedidos a proveedores, los fiados y la contabilidad básica.

## Funcionalidades principales

- Registro y control de productos e inventario.
- Alertas de stock bajo y venta de productos por fracciones.
- Registro de ventas, caja y diferentes métodos de pago.
- Gestión de pedidos e ingreso de mercancía.
- Registro de clientes fiados, abonos y saldos pendientes.
- Cierres de caja y balances contables diarios y mensuales.
- Reportes de ventas por periodo.
- Autenticación de usuarios y control de acceso por roles.

## Tecnologías

- **Spring Boot**: desarrollo del backend y la API REST.
- **MongoDB**: almacenamiento de la información del sistema.
- **Java**: lenguaje de programación.

## Alcance

El sistema está pensado para funcionar desde un navegador en computadores,
tabletas o celulares, sin requerir hardware POS especializado. Los pagos
realizados mediante Nequi o Daviplata se registrarán manualmente; no se
contempla una integración directa con estas plataformas.
